# Как устроен код сайта Araqs

Файл для человека, который не программирует. Объясняет, что где лежит,
чтобы любая следующая сессия (и вы сами) за пять минут поняли структуру.

Дата восстановления: 07.09.2026. Версия — точная копия того, что работает
на araqs.com, восстановленная из живого сайта.

---

## Откуда взялся этот код

Исходники прежнего сайта были утеряны: каждая сессия заливала файлы прямо
на Vercel, минуя хранилище. 06–07.09.2026 код восстановлен из **работающего
сайта**: переводы, оформление и структура страниц сняты с живого деплоя,
логотипы операторов взяты из ваших исходных файлов.

Что восстановлено точно (это готовые файлы, а не пересказ):
- все переводы на трёх языках — 162 строки в каждом, структура сверена, расхождений нет;
- весь файл оформления — сверен посимвольно с боевым, отличий нет;
- структура каждой страницы, включая порядок элементов и названия стилей.

Что восстановлено по смыслу (разобрано из сжатого кода сайта, возможны мелкие отличия):
- логика фильтров, поиска по маске, сортировки;
- алгоритм определения статуса номера (версия 1 — его всё равно заменит движок оценки);
- запросы к базе данных.

## Что где лежит

```

tsconfig.json         — настройка языка TypeScript
.env.example          — пример файла с адресом базы данных

messages/             ← ВСЕ ТЕКСТЫ САЙТА
  ru.json               русский
  hy.json               армянский
  en.json               английский
                        Меняете текст на сайте — меняете здесь, во всех трёх.

public/operators/     ← ЛОГОТИПЫ ОПЕРАТОРОВ (настоящие картинки)
  viva.png  ucom.png  team.png

src/app/
  globals.css         ← ВСЁ ОФОРМЛЕНИЕ: цвета, шрифты, размеры, тёмная тема
  icon.svg            ← иконка сайта во вкладке браузера
  robots.ts           ← инструкция для поисковиков
  sitemap.ts          ← карта сайта для поисковиков

  [locale]/           ← «locale» = язык. Одни и те же страницы на трёх языках.
    layout.tsx          шапка сайта и подвал — общие для всех страниц
    LanguageSwitcher.tsx  переключатель языка в шапке
    page.tsx            главная (запрос объявлений из базы)
    HomeClient.tsx      главная: фильтры, поиск по маске, таблица объявлений
    not-found.tsx       страница «не найдено»
    new/                «Разместить номер» — форма в 3 шага
    sell/               «Оценить номер» — калькулятор
    listing/[id]/       карточка одного объявления + кнопка «Связаться»
    transfer/           «Переоформление»
    rules/              «Правила размещения»
    support/            «Поддержка»
    terms/              «Условия использования»
    privacy/            «Конфиденциальность»

src/lib/
  supabase.ts         ← подключение к базе + справочники: 8 статусов с ценами,
                        3 оператора, типы номеров, эмодзи статусов
  phone.ts            ← определение оператора по коду номера (077 → Viva и т.д.)
  tierClassifier.ts   ← определение статуса номера, ВЕРСИЯ 1 (временная)
  site.ts             ← канонический адрес сайта
  araqs-number-engine.js  ← НОВЫЙ движок оценки. Лежит в проекте, но пока
                        НЕ подключён к страницам — это отдельная задача.

src/i18n/             ← настройки многоязычности (список языков, cookie)
src/middleware.ts     ← перенаправление на нужный язык

scripts/
  test-engine.mjs     ← автотест движка: 15 эталонных случаев
  mock-supabase.mjs   ← заглушка базы для проверки вёрстки без интернета
```

## Как проверить, что код рабочий

Две команды, обе обязательны перед любым деплоем:

```
npm install       — один раз, скачать библиотеки
npm run build     — собрать сайт. Должно закончиться без ошибок.
npm run test:engine — прогнать 15 эталонных случаев движка. Должно быть 15 из 15.
```

Именно шага `npm run build` раньше не делали — файлы заливались на Vercel
вслепую. Отсюда и ошибки, которые вылезали уже на живом сайте.

## Что нужно знать про базу данных

База — Supabase, проект `icyjcwuqdjkqxgylmqjl`, регион Франкфурт. Не пострадала,
работает. Три таблицы:

- **listings** — объявления (номер, оператор, тип, регион, цена, статус,
  описание, отметка о подтверждении по SMS, статус объявления, даты);
- **profiles** — профиль продавца; поле `phone` нужно, чтобы показать телефон
  покупателю после нажатия «Связаться»;
- **reports** — жалобы на объявления. Таблица есть, но **на сайте её никто не
  использует**: кнопки «Пожаловаться» в коде нет, хотя в «Условиях использования»
  она обещана.

Публичный ключ базы лежит прямо в коде — это нормально и не является утечкой:
доступ к данным ограничивают правила на стороне самой базы (RLS).

## Важное про Next.js версии 14.2.35

Известная особенность фреймворка: на вложенных страницах заголовок вкладки
может не собраться при статической сборке. Обход — строка
`export const dynamic = "force-dynamic";` в начале страницы. Она стоит на всех
страницах проекта, и это же делает сайт динамическим — так же, как работал
прежний сайт (список объявлений всегда свежий).
